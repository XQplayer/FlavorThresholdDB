# 书籍检索结果卡片优化设计

## 目标

优化《酒类风味化学》检索结果卡片，使精确检索围绕目标 CAS 实体展示，不再混入仅在正文中提及检索词、但主体属于其他物质的页面。同时把阈值按介质体系组织为可审计表格，并保留书籍索引、原页定位和人工核验信息。

## 已确认的产品规则

1. 精确检索先把 CAS、中文名、英文名或已知别名解析到书籍实体。
2. 已解析实体有 CAS 时，只显示下列两类记录：
   - `entity_cas` 与目标 CAS 相同的直接绑定记录；
   - 经 `subject_resolution` 或现有核验字段确认属于该实体的名称主体记录。
3. 不显示仅因正文出现检索词而命中的其他主体记录。例如检索氯化钠时，不再返回以谷酰基肽为主体、只在介质描述中提到氯化钠的阈值。
4. 第 607 页氯化钠等“无 CAS、但已人工核验为同一主体”的记录必须保留，并标记为“已核验上下文关联”。
5. 模糊检索保留现有文本发现能力，本次严格实体过滤只作用于精确检索。

## 卡片信息架构

### 标题区

标题区固定展示：

- 中文名或书籍主体名；
- CAS，例如 `CAS 7647-14-5`；
- 书名，例如《酒类风味化学》；
- 涉及页码；单页显示“第 607 页”，多页显示去重后的页码摘要；
- 章节与小节；
- 证据摘要，例如“CAS 直接绑定”“CAS + 已核验上下文”。

标题区用于回答“这是谁、来自哪里”，不展示冗长原文。

### 阈值体系表

阈值记录按以下固定顺序归类，只渲染有数据的组：

1. 空气
2. 水
3. 乙醇-水
4. 葡萄酒
5. 啤酒
6. 其他

“其他”保留原始介质名称，例如“果汁”“鸡汤”或“原文未说明”，不得统一改写成缺乏信息的“其他介质”。

表格列为：

- 阈值体系；
- 数值与阈值类型；
- 介质细节；
- 证据。

同一体系的多条记录在视觉上形成连续分组，但不把不同阈值类型、感官路径、介质细节或来源语义强行合并。数值保持索引中的原始单位和范围表达。

证据列区分：

- CAS 直接绑定；
- 已核验上下文关联；
- 现有中等置信上下文关联。

人工核验记录沿用索引中的 `subject_resolution`、`medium_resolution`、`source_corrections` 和 `review_status`，不在前端重新推断证据。

### 酒类应用

酒类应用独立于阈值体系显示。它用于法规限量、实际含量、生产或感官应用描述，不得混入阈值表。

当存在酒类应用时，卡片显示独立的“酒类应用”区域及记录数；内容可展开查看。没有数据时不显示该区域。

### 来源与原文

卡片底部展示去重后的来源定位，包括页码、块编号和修正提示。提供清晰的“查看原始片段原文”入口，展开后显示与当前实体记录相关的原始片段，不恢复与目标主体无关的页面全文。

## 数据与组件边界

现有 `bookSearch.js` 继续负责检索和实体解析。新增或调整的纯函数负责：

- 判断阈值记录是否属于精确命中的实体；
- 把已核验名称主体记录连接到目标实体；
- 将介质映射到六个展示体系；
- 按固定顺序生成非空分组；
- 汇总卡片级书名、页码、章节和来源定位。

`App.jsx` 仅消费已经过滤和分组的数据并渲染卡片，避免在 JSX 内重复实现实体判断和介质分类。

视觉修改限制在书籍检索结果卡片相关样式，不改动化学信息、FEMA、FlavorDB、PubChem 或普通阈值卡片。

## 状态与回退

- 精确查询可解析实体但没有书籍阈值时，显示明确的“未找到该实体的书籍阈值记录”，不回退到全文包含匹配。
- 精确查询无法解析实体时，保留当前无结果行为，不用低置信文本命中伪装成实体结果。
- 模糊查询继续返回发现型结果，并保留现有匹配原因提示。
- 缺少 CAS 的已核验名称主体记录必须显示其核验标签，不伪装为 CAS 直接绑定。

## 响应式与可访问性

- 桌面端使用四列表格。
- 窄屏下每条记录改为带字段标签的纵向块，不依赖横向滚动完成主要阅读。
- “查看原始片段原文”和“酒类应用”使用原生可展开控件或等价的键盘可操作交互。
- 状态不能只依赖颜色表达；证据标签必须包含文字。
- 保留 `prefers-reduced-motion` 兼容，不新增非必要动画。

## 测试与验收

### 检索行为

- CAS 精确检索只返回相同 CAS 的直接记录与经核验的同主体记录。
- 中文名和英文名精确检索解析到同一实体后得到同样的严格结果。
- 氯化钠精确检索保留第 607 页核验记录，排除第 437、438 页以肽类为主体的文本提及。
- 模糊检索仍可返回文本发现结果。

### 分组行为

- 介质按空气、水、乙醇-水、葡萄酒、啤酒、其他排序。
- 空组不渲染。
- 果汁等介质进入“其他”组，但原始介质名称仍可见。
- 酒类应用不进入阈值表。

### 页面与质量门槛

- 书籍检索单元测试通过，并新增上述精确过滤和分组测试。
- 现有 Python 书籍索引测试保持通过。
- ESLint 通过。
- 生产构建通过。
- 桌面与移动视口检查标题、表格、展开控件和长单位文本。
- 使用氯化钠以及同时包含空气、水、乙醇-水、葡萄酒、啤酒记录的代表性物质完成浏览器验证。

## 非目标

- 不修改 OCR、索引重建或源数据核验结果。
- 不重新定义阈值数值、单位或介质。
- 不改变模糊检索的发现型定位。
- 不重构书籍检索之外的结果卡片。
