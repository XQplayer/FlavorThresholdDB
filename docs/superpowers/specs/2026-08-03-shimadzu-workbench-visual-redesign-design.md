# 岛津分析工作台视觉重设计

## Design Read

科研仪器分析工作台。冷静精密、克制高级。`register=product`，`SOUL=6`，`SPECTACLE=3`，`DENSITY=7`。动效采用 GSAP 状态反馈与 ScrollTrigger 分层揭示。

## 设计目标

- 保留现有七步分析、模板下载、运行设置、实时监控和任务结果功能。
- 将当前大面积深绿、普通白卡片和视觉重量失衡的问题，改造成专业科研软件的操作工作台。
- 首屏明确回答三件事：系统是否可用、需要上传什么、分析将如何进行。
- 动效只服务层级、流程理解和状态反馈，不制造装饰性干扰。

## 反默认策略

拒绝两种常见默认：临床产品的青绿配色，以及科研软件的荧光终端黑。采用冷灰实验室基底、石墨文字、单一钴蓝信号色和极少量语义色。监控区使用深石墨，而不是绿色终端。

## 视觉系统

- 页面：冷灰蓝纸面，浮层为带轻微蓝灰偏色的近白色。
- 主色：钴蓝，仅用于当前节点、主按钮、焦点环和实时状态。
- 中性色：石墨、钢灰、雾灰，避免纯白、纯黑和硬灰边框。
- 圆角：外壳 28px，卡片 18px，控件 12px。
- 阴影：低对比、蓝灰偏色，只用于主工作台和悬浮监控。
- 字体：沿用 Segoe UI Variable，标题使用更紧的字距和更明确的字重，不引入装饰性字体。

## 页面结构

1. 紧凑全局导航。
2. 轻量工作台标题区，包含引擎状态、流程规模与数据边界。
3. 七步流程采用横向研究管线，当前状态具有清晰的轨道和节点反馈。
4. 输入与运行设置构成主操作区，上传卡片不再像普通表单。
5. 实时监控改为仪器控制台，工作内容与日志并列，状态和进度可快速扫读。
6. 任务开始后沿用相同视觉语言展示总进度、步骤结果和下载操作。

## 动效系统

- 首次进入：标题、状态和主工作台以 `autoAlpha + y` 依次进入。
- 滚动进入：流程、输入区和监控区使用 ScrollTrigger 一次性揭示。
- 流程节点：短距离 stagger，帮助用户按顺序阅读，不使用弹跳。
- 交互反馈：上传卡片和主按钮仅使用 transform、opacity 和 shadow。
- `prefers-reduced-motion` 时直接设置终态，不创建 ScrollTrigger。
- React 中通过 `useGSAP` 和局部 scope 自动清理动画。

## 响应式与可访问性

- 1100px 以下主操作区单列；760px 以下流程切换为纵向轨道。
- 390px 宽度不得出现横向滚动，所有下载和操作按钮触控高度不少于 44px。
- 保留 `aria-live`、状态文本、键盘焦点和非颜色状态符号。
- 页面没有 GSAP 时仍完整可用，动画为渐进增强。

## 验收

- 原有浏览器 E2E、前后端测试和构建继续通过。
- 新增视觉版本标识、GSAP 动画挂载和 reduced-motion 终态的浏览器断言。
- 桌面与移动截图无裁切、无横向溢出、控制台错误为零。
