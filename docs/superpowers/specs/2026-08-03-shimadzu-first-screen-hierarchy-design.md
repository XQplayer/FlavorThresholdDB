# 岛津分析页首屏信息层级优化设计

## 目标与边界

本轮只改善 `/shimadzu-analysis/` 的首屏阅读顺序、字体层级、运行前反馈和普通用户文案。分析流程、Web Worker、API、Supabase、文件合同、科学参数及输出结果保持不变。

## 设计决定

- 视觉语气：科研工作台、克制、精准、产品级；不增加背景图片或首屏特效。
- Hero 标题使用“岛津 GC–MS 风味数据分析工作台”，保留浏览器分析引擎状态，垂直空间缩减约 20%。
- 页面顺序调整为：Hero、账号状态、文件上传与运行设置、七步流程、实时监控、历史任务。云端登录与审批功能保留；仅本地模式显示紧凑状态条。
- 运行按钮使用现有 `.xlsx` 与 50 MB 校验规则提供即时反馈：缺文件、文件无效、权限不足和可开始四种状态均明确说明。
- 正文、辅助说明、状态/编号/日志的最小字号分别为 14px、12px、11px；只调整 Shimadzu 页面局部样式。
- 面向普通用户的界面不显示 `skill` 和 `manifest` 等实现术语，改为科研规则、运行记录与质量检查结果。
- 保留 GSAP、`prefers-reduced-motion`、键盘操作和既有 aria 属性；覆盖 375、768、1024、1440px。

## 验收

- 静态合同测试验证标题、信息顺序、反馈文案和开发术语移除。
- `pnpm run lint`、`pnpm run build`、`pnpm run test:shimadzu`、`pnpm run test:shimadzu-browser` 全部通过。
- 在四个目标视口检查无横向溢出、上传与设置优先出现、按钮状态可理解、动画降级规则仍存在。
