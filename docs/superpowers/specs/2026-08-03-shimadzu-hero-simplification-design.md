# 岛津分析页首屏精简设计

**Design Read:** 科研数据工作台 · 克制精确 · register=product · SPECTACLE=2 · hero-engine=none

**Anti-default:** 拒绝科研工具首屏堆叠营销说明和静态指标的常见做法，以动态运行状态和任务入口承担信息层级。

## 目标

降低岛津气质分析页首屏的信息重复和纵向占用，使用户更快进入账号、流程与文件上传区域，同时保留运行环境是否可用这一项动态信息。

## 改动范围

- 保留 `GC–MS FLAVOR WORKFLOW` 标识与“岛津气质数据一站式分析”主标题。
- 删除主标题下方的流程说明段落。
- 删除“流程 / 7 个审计节点”“输入 / 2 个 Excel 工作簿”“数据边界 / 当前浏览器处理”三项静态摘要。
- 保留右侧浏览器分析引擎状态卡，因为它展示的是动态运行状态，不能由后续流程区替代。
- 收紧首屏最小高度、上下内边距和左右布局间距，使状态卡与标题形成紧凑的同层信息组。
- 在窄屏继续采用单列布局，标题位于状态卡之前。

## 不改动内容

- 不修改七步处理流程、计算规则、账号审批、文件上传、实时监控和结果下载功能。
- 不修改颜色体系、字体体系、导航结构或动效机制。
- 不修改版本号，不执行线上发布。

## 验收标准

- 首屏不再出现指定说明段落与三项静态摘要。
- 引擎状态卡仍可根据 `ready`、`checking` 和 `unavailable` 状态正常显示。
- 桌面端首屏明显变矮且布局保持平衡。
- 820 px 与 620 px 响应式断点下无溢出、遮挡或异常留白。
- 现有 Shimadzu 浏览器测试、Lint 与生产构建通过。
